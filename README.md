# TGTrader

دستیار ترید شخصی برای رمزارز و فارکس. یاد می‌گیرد، بک‌تست می‌گیرد، اول کاغذی معامله می‌کند، و با
سقف‌های سختِ ریسک با پول واقعی کار می‌کند. صرافی‌هایی که API ندارند را با کنترل ماوس و کیبورد
روی خود سایت‌شان مدیریت می‌کند (Claude Computer Use).

## چه چیزی داخلش هست

| بخش | فایل | کار |
|---|---|---|
| موتور معامله | `trader/engine.py` | هر N ثانیه: کندل → اندیکاتور → رژیم بازار → سیگنال قوانین → تصمیم Claude با مهارت‌ها → مدیریت ریسک → سفارش |
| مدیریت ریسک | `trader/risk/manager.py` | سقف سرمایه، ریسک هر معامله، زیان روزانه، حداکثر پوزیشن، تریلینگ استاپ، کلید اضطراری. هیچ‌چیز نمی‌تواند این‌ها را دور بزند |
| استراتژی‌های پایه | `trader/strategy/builtin.py` | پولبک در روند (EMA)، بازگشت به میانگین در رنج (RSI + بولینگر)، شکست کانال دانچیان با حجم |
| تشخیص رژیم | `trader/strategy/regime.py` | trend_up / trend_down / range / volatile با ADX و EMAها |
| مغز | `trader/brain/claude.py` | تصمیم نهایی با `claude-opus-5` بر اساس مهارت‌ها (خروجی JSON ساخت‌یافته)، استخراج مهارت از کتاب/مقاله، چت آموزشی |
| یادگیری | `trader/knowledge/` | PDF / لینک / متن → کتابخانه‌ی قابل جستجو (FTS5) → استخراج قوانین → مهارت‌ها با چرخه‌ی پیش‌نویس → تأیید |
| مهارت‌های اولیه | `trader/knowledge/seed/*.md` | ۴۳ قانون مدیریت ریسک، ورود/خروج، رژیم، بازار و روان‌شناسی که از روز اول فعال‌اند |
| اجرا | `trader/execution/` | کاغذی، ccxt (بایبیت، بایننس، کوکوین، OKX، …)، MetaTrader 5 برای فارکس، و **Computer** برای صرافی بدون API |
| بک‌تست | `trader/backtest/engine.py` | همان قوانین و همان مدیریت ریسک روی داده‌ی تاریخی، با کارمزد و لغزش |
| رابط | `trader/gui/app.py` | PySide6، فارسی و راست‌به‌چپ: داشبورد، معاملات، مهارت‌ها، یادگیری، بک‌تست، تنظیمات |

## ساخت فایل exe روی ویندوز

1. پایتون 3.11 یا جدیدتر را از python.org نصب کن و تیک **Add to PATH** را بزن.
2. این پوشه را روی ویندوز کپی کن و در آن `scripts\build_windows.bat` را اجرا کن.
3. خروجی: `dist\TGTrader\TGTrader.exe`. برای نصب‌کننده، Inno Setup را نصب کن و `iscc scripts\installer.iss` را بزن.

یا بدون exe: `python -m venv .venv && .venv\Scripts\pip install -r requirements.txt && .venv\Scripts\python run.py`

نصب به صورت کاربر عادی است و به دسترسی ادمین نیاز ندارد. برای کنترل صفحه فقط باید پنجره‌ی صرافی
روی همان دسکتاپ باز باشد؛ چیزی خارج از آن پنجره لمس نمی‌شود.

## راه‌اندازی (به همین ترتیب)

1. **تنظیمات → Claude**: کلید API را وارد کن، «تست اتصال» را بزن.
2. **تنظیمات → بازار**: حالت `paper`، صرافی (`bybit`، `binance`، `kucoin`…)، نمادها، تایم‌فریم. کلید صرافی فقط برای حالت واقعی لازم است.
3. **تنظیمات → ریسک**: سقف سرمایه‌ی ربات (مثلاً ۵۰ دلار)، ریسک هر معامله (۱٪)، زیان روزانه (۳٪).
4. **بک‌تست**: روی نماد و تایم‌فریمت بزن و اعداد را ببین. بازده منفی یعنی این قوانین روی این بازار
   کار نمی‌کنند؛ تایم‌فریم یا نماد را عوض کن یا مهارت یاد بده.
5. **داشبورد → شروع**: کاغذی. حداقل چند هفته و ۳۰ معامله صبر کن.
6. **یادگیری**: PDF کتاب یا لینک مقاله را اضافه کن، «یادگیری» را بزن، مهارت‌های استخراج‌شده در تب
   مهارت‌ها می‌آیند (پیش‌نویس). بخوان، آن‌هایی که قبول داری را «تأیید» کن. فقط مهارت‌های تأییدشده در
   تصمیم‌ها استفاده می‌شوند. در چت هم می‌توانی مستقیم قانون بگویی.
7. وقتی نتیجه‌ی کاغذی راضی‌کننده بود: حالت `live`، کلید صرافی، سقف سرمایه کم.

## صرافی بدون API (کنترل صفحه)

در **تنظیمات → کنترل صفحه** روشن کن، در «توضیح صرافی» بنویس سایت کجا باز است و فرم سفارش کجاست.
قیمت و سیگنال همچنان از داده‌ی عمومی (بایبیت/بایننس) می‌آید؛ فقط *ثبت سفارش* روی صفحه انجام می‌شود.
با «قبل از کلیک نهایی از من بپرس» روشن، ربات قبل از دکمه‌ی خرید/فروش یک پنجره‌ی تأیید باز می‌کند.
اگر ماوس را با شدت به گوشه‌ی بالا-چپ صفحه بکشی، کنترل فوراً قطع می‌شود (pyautogui failsafe).

## چیزهایی که باید بدانی

- **هیچ تضمین سودی وجود ندارد.** اعداد بک‌تست پایه روی داده‌ی واقعی در README پایین آمده؛ روی ۱ ساعته
  و ۴ ساعته منفی است، روی روزانه‌ی BTC و ETH مثبت. به همین دلیل تایم‌فریم پیش‌فرض روزانه است.
- **ریسک از موتور تصمیم جداست.** Claude و مهارت‌ها فقط می‌گویند بخر/بفروش/نگه دار؛ اندازه و حد ضرر را
  مدیریت ریسک تعیین می‌کند و سقف‌های تنظیمات را نمی‌شود از داخل برنامه شکست.
- مهارت‌های پیش‌نویس در تصمیم‌ها استفاده نمی‌شوند تا تو تأییدشان کنی. «یاد گرفتن» یعنی این.
- `KILL_SWITCH` یک فایل خالی در پوشه‌ی داده است؛ وجودش یعنی هیچ سفارش جدیدی زده نمی‌شود.
- داده‌ها در `%APPDATA%\TGTrader` (ویندوز) یا `~/.tgtrader` هستند: `settings.json`، `trader.db`.
